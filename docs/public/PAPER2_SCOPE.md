# Second-paper scope

## Working title

Constraints on Non-Abelian Extensions of a Number-Conserving Correlated-Hopping Ladder

## Central result

The existing ANTLER microscopic grammar supports a validated Abelian digital
phase primitive but fails several necessary tests for a protected non-Abelian
operation. The paper will report the tested no-go results with their exact
scope and identify the minimum new resource required by the surviving route:
a neutral $Z_2$ link with a derived conditional dressed hop.

## Evidence required before drafting the final manuscript

1. Replay the Phase 5 to 8 scripts from a clean environment.
2. Verify every JSON result referenced by the status archive.
3. Generate figures for the perturbative-order hierarchy, local-readability
   controls, neutral-link obstruction and architecture decision tree.
4. Independently review every claim boundary and distinguish an abstract
   reference code from an ANTLER derivation.

## Excluded claims

- no non-Abelian braid;
- no protected fusion space derived from the current Hamiltonian;
- no universal gate set;
- no experimental architecture;
- no global no-go theorem for all possible ANTLER extensions.
